# LuMakH-album

Interactive 12 × 18 Photo Book with 20 pages built with React, Vite, Tailwind CSS, and `react-pageflip`.

## Features
- **12 × 18 Page Aspect Ratio**: Realistic photo album proportions (2:3 aspect ratio).
- **20 Customizable Blank Pages**: Upload your own photos onto any page.
- **Drag & Drop & Click Upload**: Easily upload images from your local machine or via URL.
- **Batch Upload**: Fill empty pages sequentially by uploading multiple images at once.
- **Cover View Toggle**: Switch between single cover view and double page spread view.
- **Local Persistence**: Automatically saves your photo album in browser storage.

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
